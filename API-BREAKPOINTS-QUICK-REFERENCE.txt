HOW TO USE:
================================================================================
1. In the UI, go to "Breakpoints" panel
2. Use the dropdown to select an API (e.g., "GET /api/users")
3. Click "Set All Breakpoints" to set all 3 breakpoints at once
   
   OR
   
4. Use "Add Single Breakpoint" section
5. Copy class name and line number from above
6. Paste and click "Add Breakpoint"

================================================================================
DEBUGGING FEATURES AVAILABLE WHEN THREAD IS SUSPENDED:
================================================================================
- Step Over: Execute current line, move to next
- Step Into: Step into method calls
- Step Out: Step out of current method
- Continue: Resume until next breakpoint
- Scope Variables: Automatically loaded when breakpoint hits
- Evaluate Expression: Evaluate variables/expressions in current scope
- Current Source Location: Shows class, method, line number
- Refresh: Reload variables and location

To suspend a thread manually:
1. Click on a thread in the "Threads" list
2. Click "⏸ Suspend" button
3. All debug features become available immediately
