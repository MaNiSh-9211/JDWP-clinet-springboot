DEBUGGING FEATURES AVAILABLE AT ALL BREAKPOINTS
================================================================================
When execution stops at ANY breakpoint (or when you manually suspend a thread),
you can use ALL of these features:

1. STEP OVER (⏭)
   - Executes the current line and moves to the next line
   - Use when you want to skip over method calls
   - Available at: ALL breakpoint locations

2. STEP INTO (⬇)
   - Steps into method calls on the current line
   - Use when you want to debug inside a method
   - Available at: ALL breakpoint locations

3. STEP OUT (⬆)
   - Steps out of the current method
   - Use when you want to return to the caller
   - Available at: ALL breakpoint locations

4. CONTINUE (▶)
   - Resumes execution until the next breakpoint
   - Use when you want to continue running
   - Available at: ALL breakpoint locations

5. EVALUATE EXPRESSION (🔍)
   - Evaluate any variable or expression in the current scope
   - Examples:
     * Variable name: "user"
     * Field access: "user.name"
     * Method call: "user.getName()"
     * Complex: "users.size()"
   - Available at: ALL breakpoint locations

6. SCOPE VARIABLES (📊)
   - Automatically loaded when breakpoint hits
   - Shows all local variables, parameters, and fields
   - Available at: ALL breakpoint locations

7. CURRENT SOURCE LOCATION (📍)
   - Shows exact class, method, and line number
   - Available at: ALL breakpoint locations

8. STACK FRAMES
   - Shows the call stack
   - Available at: ALL breakpoint locations
